# TradeDesk

Mobile-first installable web app (PWA) for trading Indian markets — index options and equity intraday —
with a defined stop loss on every trade. Strategy builder (no-code + Python), analyser, backtest, replay,
paper and live trading through Zerodha Kite, order management, data management.
